# 🍔 Swiggy Sales Data Analysis & Dashboard

## 📌 Project Overview

This project focuses on analyzing Swiggy food delivery data to extract meaningful insights using Excel.
It includes data cleaning, analysis, and an interactive dashboard to visualize key business metrics.

---

## 🎯 Objectives

* Analyze sales performance across different states and cities
* Identify top-performing restaurants and food categories
* Track monthly, weekly, and daily sales trends
* Understand customer preferences (Veg vs Non-Veg)
* Evaluate ratings and order distribution

---

## 📊 Dashboard Highlights

The dashboard provides the following insights:

* 💰 **Total Sales**: ₹53.01M
* ⭐ **Average Rating**: 4.34
* 🛒 **Average Order Value**: ₹268.51
* 📦 **Total Orders**: 197.43K
* 📈 **Sales Trends**: Monthly, Weekly, Daily
* 🍽 **Food Type Analysis**: Veg vs Non-Veg
* 🗺 **Sales by State**
* 🏙 **Top 5 Cities by Sales**
